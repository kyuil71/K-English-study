현재 상태: Google 로그인 대기 중
Firebase에서 처음 한 번 확인할 설정
Authentication에서 Google 공급자를 활성화하고, 앱을 올릴 HTTPS 도메인을 승인된 도메인에 추가하세요. 아래 규칙처럼 사용자 UID 경로를 본인만 읽고 쓰게 제한하는 것을 권장합니다.
Cloud Storage Rules
service firebase.storage {
  match /b/{bucket}/o {
    match /users/{userId}/{allPaths=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Cloud Firestore Rules
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

JSON 파일 백업

모든 날짜, 챕터, 단어/문장 암기 상태, 복습 이력을 기기에 JSON 파일로 저장합니다.

JSON 파일 복원

파일 선택창에는 .json 확장자 파일만 표시됩니다.

저장 방식

학습 데이터는 먼저 브라우저 localStorage에 즉시 저장됩니다. Google 로그인 상태에서는 같은 JSON 백업을 Firebase Cloud Storage의 사용자 전용 경로에 저장하고, Firestore에는 마지막 동기화 시각과 학습 항목 수만 기록합니다.
